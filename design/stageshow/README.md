# Audio Angel Stageshow

An authored product illustration of the player and preference flow. This is a separate React/Vite demo; it does not operate the Expo app, play audio, process content, or persist preferences.

```sh
bun install
bun run dev
```

Open port 8083. `bun run typecheck` and `bun run build` validate the standalone source. `?capture=phone-touch` displays the copied gold reference.

Source: `examples/audio-angel/index.tsx` and `audio-angel.css`. Direction and limits: `PLAN.md` and `REHEARSAL.md` beside the component. Reduced motion displays the settled preference-confirmation poster.

Stageshow kit and scripts are copied under their included MIT LICENSE and NOTICE.md. Icons: Lucide, ISC. DM Sans font: existing project dependency, SIL Open Font License. No new generated imagery.
